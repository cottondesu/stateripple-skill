# Final Audit Remediation 報告(stateripple-skill v0.1.0)

作成: 2026-10-11(JST)。対象: `stateripple-skill` リポジトリ。

Codex による Final Independent Release Audit(BLOCKING 0、MAJOR 4、MINOR 5、判定 TECHNICAL AUDIT FAIL)の指摘 F-001〜F-009 への対応記録です。

**Release Readiness: NOT READY。** 理由は 2 つです。

1. `src/stateripple/.DS_Store` が残っており、ビルドと Release Gate のパッケージ検査が失敗します。削除も移動もしていません。移動にはメンテナーの許可が必要です。

commit、push、tag、PR、Release 公開、Mandala の再初期化、既存証拠の書き換えは行っていません。

本書は `docs/` に置かれ、Source Digest の対象です。そのため最終のダイジェスト値と最後の確認監査の結果は本書に書かず、Release Gate の出力とスレッドの報告に記載します。

- ストリームの解析失敗行を数えていなかった。数えて記録し、否定ケースは 0 件を要求する。
- 証拠のプロンプトが現行カタログと一致するかを Gate が見ていなかった。一致しない証拠は数えない。
- Human Review 記録の実在しない日付、パッケージ外のシンボリックリンク、release-check の timeout 後の孫プロセス、不正な形の Replay での未捕捉例外。

## 2. まだ残る Finding

修正していないもの、または原理的に残る限界です。`docs/EVALUATION.md` に記載しています。

- **F-003 の残余(Minor)**: アクティベーションの判定は、記録されたコマンド文字列とツールイベントからの判断で、ファイルアクセスの追跡はしていません。次の場合、否定ケースで実際の読み取りを見逃します。
  - パスを名指ししない別プログラム内の読み取り(スクリプトファイル、ディレクトリを走査するインタプリタ)
  - 大文字小文字を変えたパス(評価ボリュームは大文字小文字を区別しない)
  - `xxd`、`od`、`base64` など一部のコマンドに「skill」を含まない glob を渡した場合
  - ツール名は記録されたが入力が記録されなかった場合、および型の不正なレコード
- 肯定ケースでは、`cat SKILL.md > /dev/null` のように出力を捨てた読み取りも「読込」と数えます。
- Codex は `--ignore-user-config` でもホームディレクトリの個人スキルを読みます。記録された実行でも個人の code-review スキルを読んでいます(このスキルではないので数えていません)。
- Source Digest は、リポジトリ直下の未登録ファイル(例: `.Rhistory`)を対象にしません。
- 全ファイルが未追跡の現状では、release-check の `git diff --check` と `git ls-files` の検査は対象がありません。ステージ後に再実行が必要です。
- 封印は鍵なしのハッシュです。形式を満たすレビューや記録を手で作って再封印することは検出できません。
